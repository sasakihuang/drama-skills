# 风格库：15 种动态设计风格

取自 GitHub 上的 `Vincentwei1021/mg-styles-15`，2026-11-09 的版本（提交 269f6ed），MIT 许可证，原文见同目录
`LICENSE`。原作者用 Claude 按一段提示词写代码，每种风格做了一支 10 秒的样片。剪映 Hub「动画动效」节点自带的
15 种风格，名字和顺序都和它一样。

每个文件夹是一种风格：

- `prompt.md`：原作者的完整提示词，有风格说明、招牌特征、建议画法和评审要点。原文是写给「从零做一支 10 秒片」的，
  在本技能里怎么用，见 `references/styles.md`。
- 其余文件：那支样片的画面代码，给你学手法。它跑在原作者自己的渲染框架里，不要整段搬进项目。

带过来时做了这些改动：

- 只带了画面代码（`.html`、`.js` 和画面用的 `cues.json`、`glyphs.json`），没带配乐脚本 `audio.py`、生成素材的脚本，
  也没带素材本身（照片、字体、地图数据、Blender 渲的帧）。
- 04 3D 渲染（要 Blender）、06 拼贴剪贴和 18 综艺花字（要大量照片素材）只带了提示词。
- 提示词里指向原仓库的链接改成了文字；`rubric.md`（原作者评审用的打分要点）一起带了过来。
- 08 形变的 `glyphs.json` 是从 SIL OFL 许可的字体里取的字形轮廓，仍按 OFL。
