# 复刻尺度：中度和大胆

复刻学的是结构，不是内容。只提供两档，**没有「原样照搬」这一档**：原台词换几个同义词、原画面
重画一遍，既侵权，平台也会按搬运或高度模仿处理（降权、限流甚至删除）。

## 两档对照

| 元素 | 中度（默认） | 大胆 |
|---|---|---|
| 每镜的职责、段落顺序、节奏数字、台词时间位置 | 保留 | 保留 |
| 构图、景别、机位、主体位置 | 保留 | 重新设计 |
| 动作、手势、露不露脸 | 保留 | 可以重新设计 |
| 主色调、题材类别、象征物 | 保留同色系、同类别 | 可以换 |
| 人物 | 同类型的人，全新长相 | 重新设计 |
| 服装 | 同类型、同色系，新款式 | 重新设计 |
| 场景 | 同一类地方，换一个具体地点 | 重新设计 |
| 道具、前景、背景物 | 同主题的新物件 | 重新设计 |
| 光线 | 可以换方向或时段，和色调协调 | 重新设计，要写清主光方向、软硬、色温 |
| 台词和画面文字 | 同样的卖点和作用，**全部重写** | 只保留每句的作用，换角度重写 |
| 声音 | 同类型：同性别、同年龄段、同语气的新声音（播音腔不算同语气），由创作者试听挑定；同风格的新音乐和音效；原片底下垫着配乐，新片也要垫 | 重新设计 |
| 口气 | 照原片：原片敢下判断，新稿也敢；原片吐槽，新稿也吐槽 | 可以换，要创作者点头 |

中度要锁住「风格」：红墙寺庙还是同一类中式建筑，红色还是红色。中度里把类别或色系换掉
（寺庙变现代客厅、红变灰蓝）就是走偏了。创作者点名要换的东西，优先于表里的默认。

## 写新内容时的规矩

**结构不变**（`structural_invariant`）：

- 每个新镜头对应原片的哪一镜、承担同一个职责，在复刻方案里逐镜写出来。
- 原片没有的东西不加：原片这一镜没有人、没有手、没有产品、没有字，新片这一镜也没有，除非创作者
  要加。
- 原片的台词、人物名、品牌、账号名、口头禅、片尾的账号页、二维码、平台搜索页和 logo，一个都
  不进新片。片尾是账号推广的，换成新片自己的落版，或者直接去掉。
- 生成的视频保留 AI 生成标识，不去掉、不遮挡。
- 不用真人的脸和声音去克隆，不模仿原作者本人。

**做法默认**（`craft_default`，可以按片子调整，不当门槛）：

- 每句台词只说这一镜画面里正在发生的事：说「开门」的那句就放在开门那一镜。
- 新台词的长度按原片实测的语速算（`source.profile.json` 里的每秒字数；没有就按画面字幕估，
  知识讲解类大约每秒 4.5 到 5.5 个字）。超了就删，不够就补内容。配音不靠加快、也不靠后期放慢来凑时长。
- 台词全部重写，口气照原片学。风险提示放在片尾说一次，正文不要句句打折扣
  （「不一定」「不是保证」「还要再看」）：那样像念免责声明，观众会划走。
- 反复出现的人物、商品、场景先定一份全片统一的设定，后面每镜都照它，别每镜各画各的。
- 原片节奏里最关键的那几镜（钩子、转折、兑现），新片要保留同样的时长比例。

**看个人口味**（`taste_option`）：选哪一档、新题材是什么、画风要不要变、竖屏还是横屏，由创作者定。

## 成片对照检查

成片出来后，把它和原片并排对照一遍，结果写进复刻方案的最后一节。这是给创作者看的检查，
不冒充 `$short-drama-review` 的审查结论：

| 项 | 检查什么 | 不通过时写 |
|---|---|---|
| 职责对上 | 每镜的关键动作真的发生了吗（例如「猫咬住零食」） | `动作没发生` |
| 节奏对上 | 平均镜长、第一个钩子的位置、关键镜头的时长比例和原片接近吗 | `节奏走样` |
| 风格锁住（中度） | 色系和题材类别还在吗 | `风格跑偏` |
| 前后一致 | 同一个人、同一件商品在每镜里长得一样吗 | `人物走样` / `商品走样` |
| 没有照搬 | 台词、画面文字、人物、品牌、片尾有没有原片的东西 | `照搬原片` |
| 台词对时 | 每句台词落在它对应的那一镜里吗 | `台词错位` |
| 画面不僵 | `media_profile.py --compare` 的「画面不僵」「不动的总时长」「开头三秒在动」 | `画面太僵` |
| 声音接得上 | 同上的「没有冷场」「垫了配乐」「音量够」「语速不拖」 | `冷场` / `没垫配乐` / `音量小` / `语速拖` |
| 口气对上 | 新稿是不是原片那种劲头，有没有句句打折扣 | `口气走样` |
| 标识还在 | AI 生成标识有没有被裁掉或盖住 | `标识缺失` |

不通过的只改那一镜：回到负责它的技能重做那一镜，不整片重来。
