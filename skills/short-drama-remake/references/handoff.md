# 交接：把复刻方案交给出片流程

这份交接管**剧情和实拍类**。图文动效类（K 线、图表、文字讲解）只用这里的第 1、2 步建项目、
写节奏档案，后面照 [图文动效路线](motion-graphics-route.md) 做。

复刻方案定稿后，本技能不自己写剧本、不自己出图出视频。每份创作文档仍由它原来的技能负责，
本技能只把方案交过去，并在 `复刻方案.md` 的「交接记录」里一步写一行。

## 1. 建项目

还没有项目时，按 `$short-drama` 的初始化做法建一个单集项目，首次 `init` 就带上从原片定下来的
事实：画幅取原片画幅，`--episode-count 1`，`--target-seconds` 取原片时长（四舍五入到整秒），
说明语言和提示词语言按创作者习惯。参考片目录放在项目的 `项目开发/remake/<R编号>/`。

已有项目时，参考片目录照样放在 `项目开发/remake/` 下，新片作为新的一集。

## 2. 写节奏档案

把复刻方案里的「节奏档案提议」交给 `$short-drama`，走它的创作者决策三步写进
`creator_authority.rhythm_profile`（八个字段都要写）。数字从原片推出来，默认这样取：

| 字段 | 取值 |
|---|---|
| `form` | 按画风选 `ai_live_action` 或 `motion_comic` |
| `first_hook_seconds` | 原片第一个钩子的起点，向上取整，最少 1 |
| `beat_interval_seconds_max` | 原片相邻情绪点的最大间隔，向上取整 |
| `opposed_reversals_per_episode_min` | 原片有转折就写转折次数，没有写 0 |
| `end_on_peak` | 原片停在峰值上就写 `true` |
| `reprise_previous_last_beat` | 单集复刻写 `false` |
| `vo_share_max` | 原片旁白占口播的比例，加 0.1 余量，最多 1 |
| `target_avg_shot_seconds` | 原片平均镜长 |

这些是起点，创作者可以改。档案必须由他接受后才写入：第一个停顿点已经把这份提议讲给他听，他选定
方案就算接受；他另外改了数字的，照他的写。

## 3. 依次交给各技能

每一步把下面这句请求连同复刻方案的路径交过去。对方技能照它自己的规矩做，遇到真正的创作分叉，
由它问创作者。

| 顺序 | 交给 | 请求要点 |
|---|---|---|
| 1 | `$short-drama-write` | 按复刻方案的逐镜对照写这一集的《剧本.md》：段落顺序、每段职责和时长照方案，台词全部用方案里的新台词或在其基础上润色，不得出现原片原句 |
| 2 | `$short-drama-assets` | 按「全片统一设定」拆人物、造型、地点、道具 |
| 3 | `$short-drama-image-prompts` | 资产图提示词 |
| 4 | `$short-drama-storyboard` | 分镜按逐镜对照排，镜长贴着原片，关键镜头（钩子、转折、兑现）保留原片的时长比例；短于模型最短时长的镜头照分镜技能的规矩处理 |
| 5 | `$short-drama-video-prompts` | 视频提示词 |
| 6 | `$short-drama-produce` | 先出资产图和首帧，再出视频。**每批都先报价，创作者确认才花钱**：这是第二个停顿点，由生产技能的确认闸门负责，本技能不代他确认 |
| 7 | `$short-drama-edit` | 剪辑单的切点和节奏对照原片；字幕取新剧本的台词 |

视频模型和分辨率只能由创作者亲手选，选之前先给他看价目表，做法见 `$short-drama-produce`。

## 4. 第三个停顿点：成片对照

成片出来后，按复刻尺度文档里的「成片对照检查」把新片和原片并排对一遍，结果写进复刻方案最后一节，
连同成片一起交给创作者。哪一项不通过，就只把那一镜交回负责的技能重做。
