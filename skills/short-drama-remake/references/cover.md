# 封面：每条成片配横竖两张

每条成片交出去都带两张封面，放在成片旁边：

- `<片名>-封面-竖.jpg`，1080×1920：手机上竖着刷的地方用（抖音、快手、视频号、小红书发布时选这张当封面）。
- `<片名>-封面-横.jpg`，1920×1080：要横封面的地方用（电脑端、B 站这类横着排的位置；横屏视频也用它）。

平台会裁封面：主页的格子常把竖封面裁成中间的 3:4，横封面也可能只露中间的 4:3。脚本把字和卡片都排在这块中间区域里，
裁了也不丢字。画面取自成片本身，字由脚本排：不花钱、不联网、不用 AI 出图。创作者明确要一张 AI 画的封面图时，
才走 `$short-drama-produce` 出图（gpt-image-2，每张 0.40 元，要他确认），出来的图写进 `image`，字照样由脚本排：
AI 画出来的中文常有错字。

## 什么时候做

第三个停顿点交草稿版时就做，和草稿一起给创作者看。他要改标题、换画面，就改 `封面.json` 再跑一次 `make`（十来秒）。
正式版渲好后，把 `film` 换成正式版，再跑一次 `make`。

剧情实拍类第一次做封面，这台电脑要是还没装过动画工具，`make` 会先装一次（约 200 MB，免费，全电脑共用一份，
体检脚本里的「动画工具」就是它）。装之前跟创作者说一声。

## 1. 摆出候选画面

图文动效类：

```bash
python3 <本技能目录>/scripts/cover.py frames <成片目录>/<片名>-草稿.mp4 --out <项目>/制作/封面 --animation <项目>/制作/动画
```

剧情实拍类：

```bash
python3 <本技能目录>/scripts/cover.py frames <成片目录>/成片.mp4 --out <项目>/制作/封面 --clean <成片目录>/成片-未混音.mp4
```

- `--animation`：从动画重新截每个画面讲完的那一刻。字幕和画面的小标题不画（封面的大字顶替它们），比从视频里抠的清楚。
- `--clean`：剪辑技能在成片旁边留下的 `成片-未混音.mp4` 没烧字幕，秒数和成片一样。找不到这个文件就不加，直接从成片取，
  这时画面带着字幕，挑字幕少的那几刻。
- 候选放在 `<项目>/制作/封面/候选帧/`：`汇总.jpg` 一眼看全（从左到右、从上到下是 1、2、3……），每张的秒数在输出里和
  `候选帧.json` 里。第一次运行还会起一份 `封面.json`，成片和取画面的路径都填好了。

挑法：

- 一眼看得出这条讲什么的那一刻。K 线片挑关键那根被圈住、标注打出来的时候；数字片挑大数字定住的时候；
  剧情片挑表情最足、动作最大的那一下，脸要清楚。
- 要留得出地方放字：主体偏一边或偏上下，另一边是空的。
- 不挑转场中间、发虚、全黑全白的。
- 两张可以用同一刻，也可以各挑一刻。

## 2. 写标题

- 一到两行，最多三行；每行不超过 9 个字（数字、字母算半个），加起来不超过 20 个字。
- 写观众为什么要点开：钩子、反常识的结论、一个大数字。照原片封面的套路来（看原片首帧和拆解报告里的钩子），
  字换成新片自己的，不抄原片封面上的字。
- 可以和片头标题一样，也可以说得更狠，但必须是片子里真讲了的，不做标题党。
- 重点词用 `**` 包起来，变成金色。一张最多两处。
- 系列名、第几讲写进 `tag`，是标题上面一行小字。
- 原片是毛笔大字那一路（战法、国风），`font` 写 `brush`。

## 3. 写 `封面.json`

```json
{
  "film": "<成片目录>/<片名>-草稿.mp4",
  "animation": "<项目>/制作/动画",
  "title": ["看见**放量**", "先问这三句"],
  "tag": "K线入门 · 第2讲",
  "at": 16.15,
  "vertical": {"place": "bottom"},
  "horizontal": {"at": 18.87}
}
```

| 字段 | 写什么 |
|---|---|
| `film` | 成片（草稿版或正式版）。封面出在它旁边，名字跟着它，去掉「-草稿」「-正式版」 |
| `title` | 标题，一行一项；`**重点**` 变色 |
| `tag` | 可不写。标题上面的小字 |
| `at` | 两张都用的画面：成片第几秒，从候选里抄 |
| `image` | 不用成片里的画面，用一张图（AI 出的封面图、创作者给的照片）；和 `at` 只写一个 |
| `animation` / `clean` | 从哪儿取不带字幕的画面，`frames` 已经填好；两个只写一个 |
| `vertical` / `horizontal` | 各管一张：可写 `at` 或 `image`（盖过上面那个），还有 `place`、`zoom`、`focus` |
| `place` | 字放哪：竖封面 `top`（默认）/ `middle` / `bottom`；横封面 `left`（默认）/ `center` / `right` |
| `zoom`、`focus` | 画面放大几倍（1 到 3），朝哪一点放大（`[横, 竖]`，都是 0 到 1，`[0.5, 0.5]` 是正中）：把主体放大、把边上的杂物推出画，也能把人往一边挪，给字让地方 |
| `font` | `bold`（粗黑体，默认）或 `brush`（毛笔字） |
| `accent` | 重点词的颜色，默认金色 `#ffd23f`；原片的重点是红色就写 `#ff3b3b` |

画面和封面方向一样（竖片的竖封面、横片的横封面）时，画面铺满，字压在画面上，压字的那一边会压暗。方向不一样
（竖片的横封面、横片的竖封面）时，画面做成一张圆角卡片，底下垫着它自己的模糊放大版：竖封面上字在上、卡片在下
（`place` 写 `bottom` 就反过来），横封面上字在左、卡片在右（写 `right` 就反过来）。

## 4. 出图，自己先看

```bash
python3 <本技能目录>/scripts/cover.py make <项目>/制作/封面
```

十来秒，两张写在成片旁边。两张都打开看一遍：

- 字压没压住画面主体（人脸、被圈住的那根 K 线）。压住了就换 `place`，或者用 `zoom`、`focus` 把主体挪开，或者换一刻。
- 缩小到手机主页格子那么大（宽 300 像素左右），标题还读不读得出来。
- 画面上自带的字和封面的字有没有打架。打架就换一刻。

不满意改 `封面.json` 再跑 `make`，不用重新摆候选。

## 交给创作者

和成片一起交：消息里成片的链接后面，跟上两张封面的链接，再说一句哪张用在哪：竖的发抖音、快手、视频号、小红书时
选作封面；横的给要横封面的地方。
