# 封面：每条成片配两张专属封面

每条成片交出去都带两张封面，放在成片旁边。尺寸就是抖音网页版发布页要的两种：

- `<片名>-封面-竖3比4.jpg`，1080×1440：竖封面，手机主页格子、快手、小红书、视频号也是这个比例。
- `<片名>-封面-横4比3.jpg`，1440×1080：横封面，电脑端、搜索页、B 站这类横着排的位置用。

**默认用 AI 整张出图，程序版做免费兜底。**

- **AI 版**（默认）：`gpt-image-2` 连字带图整张画，像设计师做的海报。脚本按固定模板写出图提示词：上面是标签、大标题、
  一句钩子、一行英文小字，下面是片子的核心画面，所以每条片子的封面版式一致，不靠运气。剧情实拍片附一张片子里的
  截图当参考，画出来的人和片子里是同一个。走 `$short-drama-produce` 报价、确认、出图，yoyo 中转每张 0.40 元，
  一条片两张 0.80 元。中文标题实测一字不错，但每张出完仍要逐字核对。
- **程序版**（免费、不联网）：图文动效片是海报式（发光的片名、钩子，加上从片子里抠出来的招牌画面），剧情实拍片是
  人物画面加大字。用在三种时候：这台电脑没配画图的 Key（体检里「有画图密钥」那一项）；创作者说这条不花钱；
  AI 写错了字，重出一次还错。

## 什么时候做

第三个停顿点交草稿版时就做，和草稿一起给创作者看。他要改标题或画面：AI 版改 `封面.json`、重新 `prompt` 出那一张
（再确认一次）；程序版改完再跑一次 `make`。正式版渲好后，把 `film` 换成正式版再跑一次 `make`，AI 图不用重出。

剧情实拍类第一次用程序版，这台电脑要是还没装过动画工具，`make` 会先装一次（约 200 MB，免费，全电脑共用一份，
体检脚本里的「动画工具」就是它）。装之前跟创作者说一声。

## 1. 摆出候选画面

图文动效类：

```bash
python3 <本技能目录>/scripts/cover.py frames <成片目录>/<片名>-草稿.mp4 --out <项目>/制作/封面 --animation <项目>/制作/动画
```

剧情实拍类：

```bash
python3 <本技能目录>/scripts/cover.py frames <成片目录>/成片.mp4 --out <项目>/制作/封面 --clean <成片目录>/成片-未混音.mp4
```

它在 `<项目>/制作/封面/候选帧/` 放十来张候选和汇总图（从左到右、从上到下是 1、2、3……），秒数在输出里和
`候选帧.json` 里；还会起一份 `封面.json`，成片和取画面的路径都填好了。

- `--animation`：从动画重新截每个画面讲完的那一刻，不带字幕和画面小标题。
- `--clean`：剪辑技能在成片旁边留下的 `成片-未混音.mp4` 没烧字幕，秒数和成片一样。找不到就不加，直接从成片取。
- 挑一刻写进 `at`：程序版用它当画面，剧情实拍片的 AI 版用它当人物参考（挑人物脸最清楚、表情最足的那一刻）。
  图文片挑关键那根 K 线被圈住、整张图都画完的那一刻；数字片挑大数字定住的时候。不挑转场中间、发虚、全黑全白的。

## 2. 写 `封面.json`

```json
{
  "film": "<成片目录>/<片名>-草稿.mp4",
  "animation": "<项目>/制作/动画",
  "title": ["看见**放量**"],
  "sub": "先问这三句，再决定追不追",
  "tag": "K线入门 · 第2讲",
  "en": "Three questions before you chase volume",
  "visual": "一根特别长的红色放量阳线被发光的金色圆圈圈住，一条金色水平线横穿图表，下面对应的成交量柱特别高",
  "at": 16.15
}
```

写字：

- **`title`**：片名，越短越好（两到六个字最像海报，最多两行）；每行不超过 9 个字（数字、字母算半个），加起来不超过
  20 个字。重点词用 `**` 包起来变色，一张最多两处。
- **`sub`**：标题下面一句钩子，最多 18 个字：片名说「讲什么」，这一句说「为什么要看」。照原片封面的套路写
  （看原片首帧和拆解报告里的钩子），字换成新片自己的，不抄原片封面上的字；必须是片子里真讲了的。
- **`tag`**：标题上面的小字，系列名、第几讲，可不写。**`en`**：最下面一行英文小字，只写英文，最多 40 个字母，可不写。
- **`visual`**：AI 版画什么，一两句话写片子的核心画面。K 线片写清是哪种形态、哪根被圈住、量柱怎样；剧情片写人物在干什么、
  什么表情、在哪儿。只写片子里真有的东西。
- **`look`**（可不写）：画面风格，一句话。默认是黑底金色、带暖色光晕；片子用了风格库的某种画风，就写那种画风的样子。
- **`font`**：`bold` 粗黑体（默认）、`light` 细字宽字距（素雅）、`brush` 毛笔字（跟默认模板的片头一致）。
- **`accent`**：重点词和钩子的颜色，默认金色 `#ffd23f`；原片的重点是红色就写 `#ff3b3b`。

其余字段：

| 字段 | 写什么 |
|---|---|
| `ai` | 默认 `true`。整条不用 AI 写 `false`；只某一张不用，写进 `vertical` 或 `horizontal` 里 |
| `reference` | AI 版带不带片子里的截图当参考（取 `at` 那一刻）。写了 `clean` 的剧情实拍片默认带，其余默认不带 |
| `at` / `image` | 程序版用的画面：成片第几秒，或者一张图；两个只写一个 |
| `animation` / `clean` | 从哪儿取不带字幕的画面，`frames` 已经填好；两个只写一个 |
| `style` | 程序版的样式：`poster`（海报式，写了 `animation` 的默认）或 `photo`（画面式，其余默认） |
| `crop` | 程序版海报式抠哪一块：`[左, 上, 宽, 高]`，占整个画面的比例。不写就按亮度自动找 |
| `place`、`zoom`、`focus` | 程序版字放哪、画面放大几倍、朝哪一点放大（`[横, 竖]`）；横封面的 `place` 可写 `left` / `center` / `right` / `top` / `bottom`，竖封面写 `top` / `middle` / `bottom` |
| `vertical` / `horizontal` | 各管一张，可写 `ai`、`style`、`at`、`image`、`crop`、`place`、`zoom`、`focus` |

## 3. AI 出图（每张 0.40 元，要创作者确认）

```bash
python3 <本技能目录>/scripts/cover.py prompt <项目>/制作/封面
```

它按模板把两张的出图任务单写进 `<项目>/制作/封面/AI出图/`，打印报价和 `prepare` 的命令。它自己不出图、不花钱。
接着照 `$short-drama-produce` 的硬闸门一张一张走：`--quote` 报价、`prepare` 预览、确认卡请创作者确认（例如
「确认生成：竖封面，0.40 元」）、`confirm`、`run`。出好的图在 `剧集/<EP>/制作成果/封面/cover-3x4.png` 和
`cover-4x3.png`。创作者说这条不花钱，就不走这一步，直接做下一步，出程序版。

成片要放在 `<项目>/剧集/EP001/制作成果/成片/` 这样的位置，AI 图才有地方存；不在的话 `prompt` 会直说。

## 4. 出封面、逐字核对

```bash
python3 <本技能目录>/scripts/cover.py make <项目>/制作/封面
```

它把两张封面写在成片旁边：有 AI 图就用 AI 图（裁成正好的尺寸）；没出的、或者出图以后 `封面.json` 的字和画面又改过的，
那一张用程序版，并说明原因。然后两张都打开看：

- **AI 版逐字核对**：`make` 会把该有的字列出来（标签、标题、钩子、英文）。一个字一个字对，多字、少字、错字都算错。
  错了就重出那一张（再确认一次、0.40 元）；还错，就给那一张写 `"ai": false`，再跑一次 `make` 用程序版。
  也看画面：K 线红涨绿跌对不对、人是不是片子里那个人。
- **程序版**：海报式抠的那块是不是片子最要紧的东西、有没有被切掉一截（不对就写 `crop`）；画面式的字有没有压住人脸
  （换 `place`，或者用 `zoom`、`focus` 把人挪开，或者换一刻）。
- 缩小到手机主页格子那么大（宽 300 像素左右），片名还读不读得出来。

## 交给创作者

和成片一起交：消息里成片的链接后面，跟上两张封面的链接，再说一句哪张用在哪：发抖音时竖 3:4 的传「竖封面」、
横 4:3 的传「横封面」；快手、小红书、视频号用竖的，B 站用横的。用了 AI 出图的，说一句花了多少钱。
