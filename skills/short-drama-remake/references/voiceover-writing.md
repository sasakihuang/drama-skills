# 口播稿写法：照原片的口气写新稿

用在图文动效类的旁白稿，也用在剧情类里的旁白和口播。稿子仍由 `$short-drama-write` 写进《剧本.md》，
交接时把本页的要点一起交过去。稿子写完、报配音价之前，用 `scripts/script_check.py` 量一遍。

## 写之前：先量原片

```bash
python3 <本技能目录>/scripts/script_check.py profile <参考片目录>
python3 <本技能目录>/scripts/script_check.py budget <参考片目录> --cuts <各段起点的秒数，逗号隔开>
```

- `profile` 读原片识别出来的台词，告诉你：每行几个字、每秒几个字，打折扣的词、下判断的词和「你」各有多密。
  这几个数写进拆解报告的「口气」一栏。目录里没有 `transcript.json` 时它会直说，先去识别台词；识别过了、
  里面一句都没有，它会说原片没人说话，这一步和后面的口气检查都跳过。
- `budget` 按拆解报告里的分段，算出新稿每段该写多少字。还没选音色时按原片语速给；创作者选定音色后，
  带上 `--voice-id` 和 `--speed` 再跑一次。音色之间语速能差两三成，字数要跟着变。
  它给的是一个范围，**上限是正好念满这一段的字数**（段与段之间换气的时间已经扣掉）。照下面的写法写短句，
  停顿多，同样的字数念得更久：写在范围中间，不要顶着上限写。

## 观点：默认照原片讲

复刻学的是原片怎么把一个观点讲到让人听完。默认保留原片的观点和结论，换掉的是说法、例子、数据和画面。

你认为原片哪里讲错了、讲得太满，不要自己悄悄换成另一套观点。在第一个停顿点把它列出来：原片怎么说、
问题在哪、你打算怎么改，由创作者选「照原片讲」「只改这几处」还是「换个观点」。

复刻尺度里的红线不变：不许诺收益，不喊具体买卖，不编造事实和数据来源。原片踩了红线的那一句，
换成不踩线的说法，并告诉创作者换了哪句。

## 口气：原片怎么说话，新稿就怎么说话

这几条是 `craft_default`，创作者点名要别的口气时照他的。

1. **一句只说一件事**，一口气能念完。原片每行几个字，新稿的小句也差不多长。
2. **先给结论，再给理由**。不先铺背景、最后才说结论。
3. **对着一个人说**。多用「你」，少用「我们」「大家」「用户」「投资者」。
4. **原片敢下判断，新稿也下**。「可能」「不一定」「值得关注」「需要结合来看」换成一个明确的说法。
   真有条件，就把条件说成一句硬话，不说成一串保留。
5. **提醒只说一次**，放在片尾。
6. **用嘴说的词**，不用写报告的词。「因此」「然而」「与此同时」「在一定程度上」都不是嘴里的话。
7. **每段第一句就是这段的看点**。全片第一句，要在原片钩子那几秒里说完。
8. **不搬原片的句子**。和原片连着十个字相同就算照搬；原片的口头禅和标志性的话也不用。

## 对照例子

下面三组是合成的例子，只为说明同一个意思写软了和写对味的差别。

| 原片的劲头 | 写软了 | 对味 |
|---|---|---|
| 开头直接否定观众的做法 | 很多人习惯每天称体重，但这个习惯可能并不一定科学，需要结合多方面来看。 | 你每天早上称体重？白称。体重秤量不出你想知道的那件事。 |
| 给一个硬结论，再给理由 | 在某种程度上，睡眠时长与第二天的状态往往存在一定关联，这一点值得注意。 | 睡不够六小时，第二天的你就是半个人。原因只有一个：大脑没来得及清垃圾。 |
| 有条件的判断 | 这种做法通常是可行的，不过也不能直接下结论，至少还要再观察一段时间。 | 这么做行。只有一种情况不行：连续两周没变化，立刻换方法。 |

## 写完：跑检查

```bash
python3 <本技能目录>/scripts/script_check.py check <《剧本.md》或纯文本旁白稿> --reference <参考片目录> --voice-id <选定的音色编号> --speed <语速> --audition <他选中的那条试听> --audition-text "<试听念的那一句>"
```

它逐项说通过、不通过还是提示：

每一项都会打印一行，七项：

| 项 | 量什么 |
|---|---|
| 时长对得上 | 这个音色念完全稿要多久，和原片时长比。长出一成以上不通过，给出要删多少字，或者语速调到多少；长出半成到一成写「提示……偏长」，同样给出删多少字就贴上原片 |
| 没有照搬 | 新稿和原片台词有没有连着十个字以上相同。七到九个字相同只提示：多半是讲这个题目谁都会说的半句话，看一眼是不是巧合，是就不用改 |
| 不句句打折扣 | 打折扣的词是不是比原片密得多。片尾那句固定的风险提示不算 |
| 敢下判断 | 原片常下判断时，新稿下判断的词是不是少了一半以上 |
| 对着观众说 | 原片常说「你」时，新稿的「你」是不是少了一半以上 |
| 句子不拖 | 只给提示：超过三十个字的句子是不是太多 |
| 开头够快 | 只给提示：第一句是不是比原片的钩子长 |

原片本来就很少下判断、很少说「你」时，那两项会写「这一项不比」。

- 还没选音色时不带后面四个参数，「时长对得上」只是提示。创作者选定音色后**一定带上音色重跑一次**，
  过了再去报全片配音的价。配完才发现超时，就只能花钱重配或者接受片子变长。
- 不通过的项，改稿再跑。是创作者点名要的（比如他就要更稳重的口气），在复刻方案里写一句原因，不硬改。
- 不要为了让数字过关去凑词：往稿子里撒几个「就是」「其实」，数是过了，话没变硬。数字不过，改的是那句话的说法。
- 图文动效的旁白稿加 `--voice-over-only`，只看旁白行。剧本里一句台词和旁白都没有时，它会直说没有可查的。
- 这些数只查得出稿子有没有偏离原片的说话方式，查不出一句话好不好。跑完还要对着原片的台词逐段读一遍。
- 剧情类的对白不铺满全片，「时长对得上」对它没有意义，只看其余几项。
